# 📊 COVID-19 Data Visualization Dashboard

This project analyzes and visualizes COVID-19 data to understand the global impact of the pandemic.

🔗 🔗 [Live Demo →](https://laxmiyadav708-dataviz-covid19-impact-app-ucbg4y.streamlit.app)

## 🚀 Features

* Country-wise COVID analysis
* Data visualization using charts
* Interactive dashboard
* Real-time data exploration

## 🛠 Tech Stack

* Python
* Pandas
* Matplotlib / Plotly
* Streamlit / Flask

## 📂 Project Structure

```
dataviz-covid19-impact
│
├── app.py
├── country_wise_latest.csv
├── requirements.txt
└── README.md
```

## ▶️ How to Run

1. Clone the repository

```
git clone https://github.com/laxmiyadav708/dataviz-covid19-impact.git
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the application

```
python app.py
```

## 📈 Output

The dashboard displays visual insights into COVID-19 cases, deaths, and recoveries across different countries.
